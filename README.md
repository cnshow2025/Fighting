# Fighting（手机局域网射击游戏）

一只安卓手机开热点并运行服务器，其他人连上这个热点后，用手机浏览器打开网址就能玩。不用联网，也不耗流量。

## 玩法

- 红队、蓝队各最多 5 人。画面可以选 **2D 俯视**、**3D 斜上方**、**第一人称** 或 **第三人称**（见下面“画面视角”）。
- **左半屏拖动** = 移动；**右半屏拖动** = 瞄准。推远一点会自动开火（摇杆变红）。
- 地图上有遮蔽物（棕色方块）。敌人躲在遮蔽物后面时，你看不到他（服务器根本不会把他的位置发给你）。他一走出来，你就能看到并射击他。子弹也会被遮蔽物挡住。
- 每人 3 点血（中 3 枪倒下），**子弹无限**，倒下后不能复活。
- 人物圆圈分成 3 块：中 1 枪有 1 块变黑，中 2 枪有 2 块变黑，一眼就能看出还剩几点血。
- **三关三战两胜**：一场比赛最多打 3 局，第 1 局在第 1 关、第 2 局在第 2 关、第 3 局在第 3 关，先赢 2 关的队获胜（2:0 就不用打第 3 关）。
- 每关 1 分钟：
  - 先把对方全部击倒的一队赢这一关；
  - 时间到时，存活人数多的一队赢这一关；人数相同算平局，不计分，重打同一关。
- 每关结束后，房主按 **“下一关”** 继续；整场比赛结束后，房主按 **“再来一场”** 从第 1 关重新开始。

## 画面视角

- 大厅里有 **“2D | 3D | 第一人称 | 第三人称”** 切换，每个人在自己的手机上选，会记住上次的选择。同一局里每个人可以用不同的视角，规则完全一样。
- **2D、3D**（斜上方）：左边拖动移动、右边拖动瞄准，推远一点自动开火。
- **第一人称**（从眼睛看出去，像《吃鸡》）和 **第三人称**（镜头在自己背后）：
  - 左边拖动移动（往上是往前走，左右是横着走）；
  - 右半边屏幕左右拖动是转身；
  - 按住右下角的 **“开火”** 键射击，子弹打向画面正中间的准星；
  - 左上角有小地图：掩体、救护包、队友、看得到的敌人，以及自己（白色箭头指向你面对的方向）。躲在掩体后面的敌人在小地图上一样看不到。
  - 倒下后镜头会拉高，看整张地图。
- 掩体、人物、子弹、救护包都是立体的（为了手机顺畅，没有光照影子，掩体后面看不到的区域也不会变暗，但躲在后面的敌人一样看不到）；名字和血条显示在人物头顶上方（3 个小长方块，中一枪黑一块），不会挡住人物。
- 3D 比较吃手机效能。旧手机如果觉得卡，切回 2D 就好；如果手机不支持 3D，会自动改用 2D。

## 三个关卡

| 关卡 | 地图 | 掩体 | 电脑难度 |
|---|---|---|---|
| 第 1 关 · 仓库 | 很多木箱和沙包 | 多，好躲 | 简单 |
| 第 2 关 · 废墟 | 断墙为主，墙上有缺口可以穿过 | 中等 | 普通 |
| 第 3 关 · 荒野 | 零星几块石头和沙包 | 少，很开阔 | 困难 |

- **木箱**挨 4 枪、**沙包**挨 6 枪会碎掉，碎掉后就不能再躲。**断墙**和**石头**打不坏。
- **救护包**（第 2、3 关）：地图上随机放 3 个白底红十字的救护包，大家都看得到。受伤时走过去就补满血（满血走过去不会浪费掉），被吃掉 15 秒后会在别的随机位置再出现。电脑受伤时也会去吃。
- 倒下后会看到还活着的队友的视野。

## 邀请朋友（扫码进队）

- 房主在大厅里按红队或蓝队框里的 **“邀请朋友”**，屏幕会显示加入那一队的二维码。
- 朋友先连上热点，再用手机相机扫码，会打开游戏并显示“你被邀请加入红队”。输入名字后按“加入”，就直接进入那一队。
- 二维码里是热点手机的地址。如果朋友扫码后打不开，说明地址不对：在 设置 > 热点 里查看本机 IP，改在二维码下面的地址栏里（例如 `192.168.43.1:3000`），二维码会自动更新。
- 这一队已满 5 人时，会提示朋友自己选另一队。
- 游戏进行中想邀请新朋友：房主按画面右上角的 **“回大厅”**（会先问一次确认），这一局中止，所有人回到大厅，队伍保留，邀请完再按“开始游戏”。

## 电脑补位

- 房主可以在大厅里用 **“电脑补位”** 开关决定要不要电脑（默认打开）。关掉时只有真人对打，两队都至少要有 1 人。
- 打开时，每队至少 3 人，开局时自动用电脑补上；如果有一队超过 3 人，另一队也补到一样多。每队最多 5 人。
  - 一个人选蓝队 → 蓝队补 2 个、红队补 3 个电脑，变成 3v3。
  - 4 个人对 1 个人 → 蓝队补 3 个电脑，变成 4v4。
- 电脑难度随关卡自动提升（简单 → 普通 → 困难），差别在电脑的反应速度、瞄准准度和会不会躲掩体。
- 电脑和真人规则一样：躲在遮蔽物后面它也看不到你，不会透视。它看不到你时会到处搜索，或去你最后出现的地方找你。
- 一个人玩时，同样先在 Termux 里 `npm start`，然后在同一只手机上打开 `http://localhost:3000`。

## 架设方法（安卓手机 + Termux）

**第一次准备（需要联网一次）**

1. 在开热点的安卓手机上安装 [Termux](https://f-droid.org/packages/com.termux/)（建议从 F-Droid 下载）。
2. 打开 Termux，依次输入：
   ```sh
   pkg update
   pkg install nodejs git
   git clone https://github.com/cnshow2025/Fighting.git
   cd Fighting
   npm install
   ```

**每次开玩**

1. 打开手机的**个人热点**，让其他人的手机连上。
2. 在 Termux 里输入：
   ```sh
   cd Fighting
   npm start
   ```
3. 屏幕会显示网址，例如 `http://192.168.43.1:3000`。如果没显示 IP，可以在 设置 > 热点 里查看本机 IP，常见的是 `192.168.43.1`。
4. 其他人用手机浏览器（Chrome 或 Safari）打开这个网址。开热点的手机本人打开 `http://localhost:3000`。
5. 输入名字 → 选队 → 第一个进入的人是房主（👑），由房主按“开始游戏”。
6. 建议**横屏**玩。点一下屏幕会自动尝试全屏。

**iPhone 怎么全屏**：iPhone 的 Safari 和 Chrome 都不允许网页自动全屏。请用原始网址（不要用带队伍的邀请网址）点 **分享 → 添加到主屏幕**，以后从主屏幕图标打开就没有网址栏。再把“屏幕方向锁定”关掉，横过来玩。

> 提示：玩的时候不要让 Termux 被系统关掉。可以在 Termux 的通知栏里点 “Acquire wakelock”。

## 调整参数

在 `server.js` 顶部可以修改：每局时长 `MATCH_TIME`、每队最少人数 `MIN_TEAM`、血量 `MAX_HP`、射速 `FIRE_COOLDOWN`、移动速度 `PLAYER_SPEED`，赢几关获胜 `WIN_ROUNDS`，还有三个关卡的地图和电脑难度 `LEVELS`。

## 文件说明

- `server.js`：服务器，负责游戏逻辑、视线计算和胜负判定。
- `public/index.html`：页面（名字输入、大厅）。
- `public/game.js`：手机端，负责 2D 画面、触控摇杆和上方的文字信息。
- `public/render3d.js`：3D 画面。
- `public/three.module.min.js`：开源 3D 程序库 Three.js（MIT 授权），放在项目里所以不用联网。
- `public/qrcode.js`：开源二维码程序（MIT 授权）。
